# Alberta (open-alberta-ca)

Alberta is a open data portal open-data portal for Canada running **CKAN**, exposing a standardized catalog API over ~33,436 datasets.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/open-alberta-ca/refs/heads/main/apis.yml)

**Run:** [Capabilities Using Naftiko](https://github.com/naftiko/fleet?utm_source=api-evangelist&utm_medium=readme&utm_campaign=open-alberta-ca-api-evangelist&utm_content=repo)

## Type
- **kind:** government  ·  **software:** CKAN  ·  **version:** 2.10.6

## API
- **Alberta CKAN Action API** — base `https://open.alberta.ca/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://open.alberta.ca)
- Live endpoint verified: `https://open.alberta.ca/api/3/action/status_show` · ~33,436 datasets
